# Talabek Phone

تطبيق متجر إلكتروني عربي كامل لـبيع الهواتف والملحقات، مع واجهة RTL، سلة مشتريات، نموذج طلب، لوحة إدارة، وتوافق PWA للتثبيت على Android.

## المميزات
- واجهة عربية RTL كاملة
- صفحة رئيسية تعرض الهواتف والملحقات
- سلة مشتريات مع تعديل الكمية
- نموذج طلب العميل
- لوحة إدارة للمنتجات والطلبات
- دعم PWA للتثبيت على الهاتف
- حفظ البيانات في المتصفح عبر localStorage

## التشغيل
1. افتح الطرفية داخل المستودع.
2. نفّذ:

```bash
python3 -m http.server 8000
```

3. افتح المتصفح على:

```text
http://localhost:8000
```

## ملاحظات
- يعمل المشروع بالكامل على الواجهة الأمامية فقط.
- البيانات تُحفظ محلياً داخل المتصفح.
- لن تحتاج إلى أي مكتبات أو خدمات خارجية لتجربته.

## هيكلة المشروع
- `index.html` — الصفحة الرئيسية
- `styles.css` — تنسيق واجهة التطبيق
- `app.js` — منطق المتجر ولوحة الإدارة
- `manifest.webmanifest` — إعدادات التطبيق المحمول
- `service-worker.js` — الخدمة الخلفية للـ PWA
- `assets/` — أيقونات التطبيق
